# Healthcare Claims Data Pipeline

A batch data pipeline that loads synthetic member, medical-claims and pharmacy-claims data into PostgreSQL. Bad records are quarantined instead of loaded, every row is reconciled from source to target, and reporting tables show cost by plan, member, month and drug. It is orchestrated with Apache Airflow, runs in Docker, and is tested in GitHub Actions on every push.

**Why it exists:** in healthcare analytics, one bad claim (a missing member ID, a duplicate or a negative payment) silently skews cost reports. This pipeline catches those rows, keeps them for review and proves that nothing was lost along the way.

> All data is synthetic, generated by `pipeline/generate.py`. No real patient data (PHI) is used.

## What it does

```
generate.py ──> raw CSVs ──> quality.py ──┬──> stg_* tables (clean)   ──> marts.sql ──> mart_* reporting tables
                                          └──> quarantine_* tables (rejected rows + reason)
                         reconcile(): source rows == loaded + quarantined, and DB row counts == rows sent
```

| Step | File | Details |
| --- | --- | --- |
| Generate | `pipeline/generate.py` | 500 members, ~5,000 medical claims, 3,000 pharmacy claims; ~2% of claims deliberately dirty |
| Quality checks | `pipeline/quality.py` | null member ID, unknown member (referential integrity), negative paid, paid > billed, duplicate claim ID, invalid days supply |
| Load | `pipeline/load.py` | clean rows → `stg_*`, rejected rows → `quarantine_*` with `reject_reason`; source-to-target reconciliation on both sides |
| Transform | `sql/marts.sql` | `mart_member_monthly_cost`, `mart_plan_cost_summary`, `mart_top_drugs` (ANSI SQL; runs on PostgreSQL and SQLite) |
| Orchestrate | `dags/claims_pipeline_dag.py` | daily Airflow DAG, 2 retries, 1-hour SLA, failure alert callback, fails the run if >10% of rows are rejected |
| CI | `.github/workflows/ci.yml` | pytest on every push, then a full pipeline run against a PostgreSQL service container |

## Run it

**Quick local run (SQLite, no Docker):**
```bash
pip install -r requirements.txt
pytest -q                                  # 3 tests
python -m pipeline.generate --out data/raw
python -m pipeline.load                    # prints the quality report
```

**Full stack (PostgreSQL + Airflow in Docker):**
```bash
docker compose up
# Airflow UI: http://localhost:8080 (the admin password is printed in the airflow container log)
# Turn on the `claims_pipeline` DAG and trigger it
```
